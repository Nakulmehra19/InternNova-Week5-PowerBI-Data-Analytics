# Week 5 Assignment – Power BI Data Analytics

## InternNova Data Analytics Internship

### Project Title
**Superstore Sales Analysis Dashboard**

## 1. Overview
This project uses Microsoft Power BI to analyze the Sample Superstore dataset. It demonstrates data cleaning, data modeling, DAX calculations, data visualization, and interactive dashboard development.

## 2. Objectives
- Import and inspect the Sample Superstore dataset.
- Check data quality and correct column data types.
- Create a customer dimension table.
- Establish relationships between tables.
- Create DAX measures and KPI cards.
- Build interactive charts and slicers.
- Identify business insights and recommendations.

## 3. Tools and Technologies
- Microsoft Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- Microsoft Excel

## 4. Dataset
**File:** `Sample - Superstore.xlsx`

The dataset contains order dates, customer details, product categories, regions, sales, quantity, discount, and profit.

## 5. Tasks Completed
1. Data import and inspection
2. Data quality checking and preparation
3. Data type verification and date sorting
4. Creation of the `DimCustomer` table
5. Data modeling and relationships
6. DAX measures and KPI cards
7. Sales visualizations and interactive dashboard
8. Business insights and recommendations

## 6. DAX Measures
- **Total Sales:** Calculates total sales.
- **Average Sales:** Calculates average sales per row.
- **Total Records:** Counts rows in the dataset.
- **Maximum Sales:** Finds the highest sales value.
- **Minimum Sales:** Finds the lowest sales value.
- **Sales Percentage:** Calculates the sales share according to the defined filter context.

## 7. Dashboard Visualizations
- Sales by Category — Bar Chart
- Sales Trend by Year — Line Chart
- Sales by Customer Segment — Donut Chart
- Product Sales and Profit — Table
- KPI Cards for key sales metrics
- Category and Region slicers

## 8. Business Insights
The dashboard helps compare sales across categories, years, customer segments, and regions. Sales and profit are reviewed together to support better inventory, pricing, and marketing decisions.

## 10. Conclusion
This project demonstrates how Power BI can transform raw sales data into an interactive dashboard for business analysis and data-driven decision-making.
